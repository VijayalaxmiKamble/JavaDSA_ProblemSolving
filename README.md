# 📘 Array Programs Covered

The repository currently includes various array-based problem-solving programs.

## ✅ Array Pair Programs

### 🔹 ArrayPair.java
- Program based on array pair operations
- Prints possible pairs from array

### 🔹 ArrayPair2.java
- Another variation of pair finding logic

### 🔹 ArrayPairSum.java
- Find pairs whose sum matches a target value

Example:

```text
Input:
1 2 3 4 5

Target:
5

Output:
(1,4)
(2,3)
```

---

# 📘 Difference Pair Programs

### 🔹 DifferencePair.java
- Find pairs having a specific difference

Example:

```text
Input:
1 3 5 7

Difference:
2

Output:
(1,3)
(3,5)
(5,7)
```

---

# 📘 Greater Element Programs

### 🔹 FirstValueGreaterPair.java
- Find first greater value pair in array
- Useful for comparison-based logic

# 📘 Sorting and Merging Programs

### 🔹 Merge2SortedArray.java
- Merge two sorted arrays into a single sorted array

Example:

```text
Array 1:
1 3 5

Array 2:
2 4 6

Output:
1 2 3 4 5 6
```

# 📘 Unique Element Programs

### 🔹 PrintCountOfUniqueElemenets.java
- Count total unique elements in array

Example:

```text
Input:

Output:
Unique Elements Count = 4
```

### 🔹 PrintUniqueElements.java
- Print only unique/distinct elements

# 📘 Repeating Element Programs

### 🔹 PrintLargestReapitingElement.java
- Find largest repeating element in array

### 🔹 PrintReapetedElementsOnly.java
- Print only repeated elements

### 🔹 PrintElementWithoutReapiting.java
- Print non-repeating elements from array

# 📘 Frequency Programs

### 🔹 PrintOccerenceOfElementFromSortedArray.java
- Count occurrence/frequency of elements in sorted array

Example:

```text
Input:
1 1 2 2 2 3 4

Output:
1 -> 2 times
2 -> 3 times
3 -> 1 time
4 -> 1 time
```

---

# 📘 Common Element Programs

### 🔹 PrintReapetedElementFrom2SortedArray.java
- Print common repeated elements from two sorted arrays

Example:

```text
Array 1:
1 2 3 4

Array 2:
2 4 6 8

Output:
2 4
```
